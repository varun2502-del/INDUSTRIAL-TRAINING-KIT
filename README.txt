DATA CLASSIFICATION USING AI

Project Title: Data Classification Using AI using Decision Tree Classifier

Objective:
To build a basic Machine Learning classification model that can learn from a dataset, classify new data, and evaluate its performance using the Decision Tree algorithm.

Requirements:

* Python 3.x
* VS Code (or any Python IDE)
* scikit-learn library

Features:

1. Loads the Iris dataset.
2. Splits the dataset into training and testing sets.
3. Trains a Decision Tree Classification model.
4. Predicts the class of test data.
5. Calculates the accuracy of the model.
6. Predicts the class of new sample data.

How to Run:

1. Open Command Prompt or Terminal.
2. Navigate to the project folder.
3. Install the required library:
   pip install scikit-learn
4. Run the command:
   python project2.py
   or
   py project2.py

Working:

1. The Iris dataset is loaded using scikit-learn.
2. The dataset is divided into training data (80%) and testing data (20%).
3. A Decision Tree Classifier is created.
4. The model is trained using the training data.
5. The trained model predicts the classes of the test data.
6. The accuracy of the model is displayed.
7. The model predicts the class of a new flower sample.

Sample Output:

Accuracy: 1.0

Predicted Class: setosa

Technologies Used:

* Python
* scikit-learn
* Decision Tree Classifier
* Iris Dataset
* Train-Test Split
* Machine Learning

Outcome:

This project demonstrates the basic concepts of Machine Learning and Supervised Learning. It shows how to load a dataset, train a classification model, test its performance, calculate accuracy, and predict the class of new data using the Decision Tree algorithm.
